# Swift Ship Tracker

A Salesforce-powered parcel tracking and management system with an Agentforce AI chatbot for automated shipment updates and customer support.

## Project Overview
Swift Ship Tracker helps businesses and customers monitor parcel status efficiently. It uses Salesforce for data management and integrates an AI-powered chatbot to provide quick shipment updates, support, and notifications.

## Features
- Real-time parcel tracking
- Automated shipment status updates
- AI chatbot support via Agentforce
- Salesforce-based data management
- Easy tracking and customer support workflow

- Salesforce

## How It Works
1. Customers enter a tracking ID.
2. The system fetches shipment details from Salesforce.
3. The AI chatbot provides status updates and support.
4. Users receive automated notifications and tracking assistance.
